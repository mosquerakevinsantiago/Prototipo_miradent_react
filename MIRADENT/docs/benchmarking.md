# Benchmarking solicitado

Los apuntes del proyecto mencionan revisar estas referencias:

- Los Cines.
- Airbnb.
- Otra plataforma de odontología (nombre por confirmar).
- Barbería Lord's (Freshu).

## Aspectos que conviene comparar

| Aspecto | Qué observar en cada plataforma | Aplicación en MIRADENT |
|---|---|---|
| Consulta de disponibilidad | Cómo se muestran fechas y horas libres | El paciente ve las horas habilitadas por odontólogo |
| Selección del profesional | Si se puede elegir una persona o categoría | El paciente selecciona odontólogo y especialidad |
| Reserva | Pasos y datos solicitados | Servicio, odontólogo, fecha, hora y comentarios |
| Confirmación | Cómo se informa el estado de la reserva | La cita se registra como Pendiente y el administrador puede cambiar su estado |
| Administración | Cómo se configuran agendas y recursos | El administrador publica horarios para cada odontólogo |

Esta tabla es una guía de análisis para realizar el benchmarking. No afirma que las plataformas mencionadas tengan una función concreta; el equipo debe visitar cada referencia y completar sus observaciones.
